# Library Management System (CLI)

A beginner-friendly Command Line Interface (CLI) application built using Python to manage library book records, track borrowed items, and save data using JSON file persistence.

## Features
- View all available and borrowed books
- Add new books to the system catalog
- Borrow and return books with automatic status updates
- Data persistence using JSON (`library_data.json`)

## How to Run
1. Ensure Python 3.x is installed on your system.
2. Run `main.py` in your terminal:
   ```bash
   python main.py
